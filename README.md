# Bangla-English Food Assistant

A food quantity assistant for ordinary households in Bangladesh. It helps work out how much raw ingredient to buy for a given number of adults and children.

Answers are given in both Bangla and English. The project combines an AI model to understand the question, a Google Sheets ingredient database, and a Python function that does the calculation.

This is a beginner learning project and a work in progress. The current quantities are my own estimates and are labelled as such. I plan to replace them with data collected from real households.
